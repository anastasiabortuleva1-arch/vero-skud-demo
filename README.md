# Vero — СКУД: передача демоверсии

Готовый пакет демоверсии от 7 октября 2026 года. Интерфейсы заказчика и исполнителя, заявки, коммерческие предложения, монтаж, регистрация, мониторинг, аналитика и расторжение договора.

## Что скачать

- **vero-skud-source.zip** — все исходники, package-lock.json и конфигурация сборки.
- **vero-skud-build.zip** — уже собранный статический сайт. Можно сразу разместить на хостинге.
- **vero-skud-repository.bundle** — исходники с Git-историей для разработчика, который предпочитает Git.

Файлы внутри исходного архива лежат в папке `vero-skud-demo`. Для загрузки архива откройте файл в GitHub и нажмите **Download raw file**.

## Запуск и повторная сборка из исходников

Установите Node.js 24 LTS, распакуйте `vero-skud-source.zip` и выполните:

```sh
cd vero-skud-demo
npm ci
npm run dev
```

Сборка для размещения:

```sh
npm run build
```

Результат — папка `dist`. Более подробная инструкция находится в README внутри исходного архива.

Альтернативно можно восстановить полноценный репозиторий из bundle:

```sh
git clone vero-skud-repository.bundle vero-skud-demo
cd vero-skud-demo
npm ci
npm run build
```

## Размещение готовой сборки

Распакуйте `vero-skud-build.zip` и разместите **содержимое архива** в корне сайта. `index.html` должен лежать в корне публикации. Настройте SPA fallback: неизвестные маршруты должны открывать `index.html`, а существующие файлы — отдаваться напрямую. Это необходимо для обновления страниц вида `/skud/responses`.

Для сборки на хостинге используйте исходники: команда `npm run build`, каталог результата `dist`. В исходниках приложены настройки Vercel и Netlify. Серверная часть и переменные окружения не нужны.

## Что важно знать

Это демонстрационный интерфейс. Данные хранятся в памяти браузера и сбрасываются при полной перезагрузке. Подпись, платежи, уведомления и взаимодействие с внешними системами имитируются. В шапке — переключение ролей, внизу — панель управления демо.

Перед передачей проверены TypeScript, production-сборка и основные сценарии в браузере.
